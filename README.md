# MagFlow.ai

AI-powered accounts payable automation. Capture, match, approve, and pay invoices from one platform.

This repo is the MagFlow.ai marketing site: a responsive landing page covering invoice capture, two- and three-way matching, supplier self-service, global e-invoicing, and payment.

## Stack

- TanStack Start
- React
- Vite
- Tailwind CSS v4
- Motion

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Brand

Red and white palette drawn from AssetGenie: brand `#ec2020`, ink `#231645`, canvas white.
